Project 01 Open source

Rendure

Multi-agent resume tailoring. Open source.

Rendure takes a resume and a job description and produces typeset RenderCV YAML. The hard part is not generation, it is refusing to invent things. Language models will happily add a framework you have never touched if the job description mentions it. So Rendure runs a two-stage Generation to QA pipeline. The generation agent produces a candidate resume; a separate QA agent audits every claim back to the source resume under strict grounding rules and rejects anything unsupported. Splitting these into two agents with opposing incentives works far better than one agent asked politely to be accurate.

Project 02

Agent orchestration platform

Long-running multi-agent pipelines coordinated through Postgres.

A set of specialised agents that run continuously and hand work down a chain, each stage enriching a shared record. Built to answer a question I kept hitting: how do you run agents for weeks rather than minutes? The answer turned out to be avoiding agent-to-agent chat entirely. Agents coordinate through a Postgres state machine and cron scheduling, not by talking to each other. Every transition is a durable row, so a crashed agent resumes from state rather than losing the run.

  • 01Model routing by stage. Structured extraction runs on cheap fast models; reasoning-heavy stages route to larger ones.
  • 02Supervisor loops over fixed schedules. A heartbeat process watches agent health and escalates to a human only when something needs it.
  • 03Evidence requirements. Every agent output carries typed provenance, and unverifiable claims are labelled as inferred rather than asserted.
Postgres/TypeScript/Python/OpenRouter/Self-hosted
Project 03

Personal RAG

Query my own notes and documentation from Telegram.

Retrieval over several years of Obsidian notes and development docs, built on R2R with pgvector and Cohere embeddings and reranking. The reranking stage mattered more than the embedding model; raw vector search kept surfacing plausible but wrong chunks. Runs on my homelab alongside Obsidian LiveSync over CouchDB, behind Caddy.
