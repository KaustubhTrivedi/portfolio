Selected work

Two things I built end-to-end, and the hard part of each.

Rendure

01

An open-source, multi-agent resume tailoring platform that adapts a resume to a job description without inventing anything.

The hard part

The core risk in any LLM resume tool is fabrication. Instead of one generation pass, I built a generation-then-QA loop: one stage tailors, a separate stage audits the output against the source for invented claims and keyword fit. A structured RenderCV YAML acts as the single source of truth, so output stays deterministic and ATS-parseable.

Outcome

Open-source, deployed publicly, launched across developer communities including r/selfhosted and r/LocalLLaMA. [PLACEHOLDER — stars / users]

Magpie

02

A geospatial web application that renders and queries 58,000+ spatial data points interactively, built as my MSc final project.

The hard part

The challenge with this much spatial data is keeping the map usable. Shipping every point to the browser falls over fast. So the work was in the data layer: a Go backend serving viewport-bounded spatial queries so only the points currently in view get fetched, plus aggregation at lower zoom levels so the client never has to draw tens of thousands of markers at once.

Outcome

Delivered as my MSc Computer Science final project at TU Dublin, handling the full 58,000+ point dataset interactively. [PLACEHOLDER — grade / metric]
